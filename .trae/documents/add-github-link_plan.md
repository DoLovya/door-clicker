# 添加 GitHub 链接计划

## 需求分析
在项目的 Web 页面中添加 GitHub 仓库链接 `https://github.com/DoLovya/door-clicker`

## 位置选择

### 1. 开门页 (door.html)
- **位置**: 页脚 footer 区域
- **原因**: 这是用户最常访问的页面，页脚是放置次要链接的标准位置
- **样式**: 与现有的"配置"链接保持一致，使用 GitHub 图标

### 2. 配置页 (index.html)
- **位置**: 顶部导航栏
- **原因**: 管理员可能需要查看源代码
- **样式**: 与"返回开门页"链接风格统一

### 3. 登录页 (login.html)
- **位置**: 底部返回链接旁边
- **原因**: 保持一致性

## CSS 修改

### door.css
```css
/* 添加页脚分隔符 */
.footer-sep {
    margin: 0 8px;
    color: rgba(255, 255, 255, 0.4);
}

.footer a svg {
    vertical-align: middle;
    margin-right: 4px;
}
```

### login.css
```css
/* GitHub 链接样式 (与 back-link 共用) */
.back-link svg {
    vertical-align: middle;
    margin-right: 4px;
}
```

## 实施步骤

1. 修改 door.html - 在 footer 添加 GitHub 链接
2. 修改 door.css - 添加分隔符和 SVG 样式
3. 修改 login.html - 在底部添加 GitHub 链接
4. 修改 login.css - 添加 SVG 样式
5. 测试所有页面确保链接正确显示

## 风险评估
- **低风险**: 仅添加静态链接，不影响现有功能
- **兼容性**: 使用内联 SVG 确保在所有浏览器正常显示
